# ML & MCDM Optimization Research

Python implementations developed during PhD research in Applied Mathematics.

## Projects

- **Hybrid MCDM with Random Forest**: Interval-valued fuzzy decision-making combining ELECTRE, TOPSIS, WASPAS with Random Forest regression
- **DEA Efficiency Evaluation**: Congestion detection and scaled efficiency measurement
- **Healthcare Analytics**: Provincial breast cancer risk ranking using TOPSIS
- **Fuzzy WASPAS**: Landfill site selection under uncertainty

## Tech Stack
Python, NumPy, Pandas, Scikit-learn
